# UI Library acceptance gates
Every item must have: unique permanent ID, source HTML, explicit theme compatibility, keyboard interactions, focus-visible, disabled state where applicable, responsive behavior (320px through desktop), zoom/reflow, no unbounded overflow, labels and examples free of misleading claims.

A static demonstration is **not a production verification**. Advance `draft-demo` → `reviewed` only when a reviewer records browser screenshots or tests at 360px, 768px, 1280px, keyboard-only, 200% zoom and reduced motion. Document limitations per variant; do not invent automated test results.
