# SabPuja reference and provenance
Reference gallery: https://sabpuja.github.io/theme/components/
Repository inspected: https://github.com/sabpuja/sabpuja.github.io (components and blocks pages)

What we adapted conceptually: canonical IDs, component/variant hierarchy, searchable live previews, responsive viewport controls, and separation of styling foundations.
What we did not copy: Sabpuja brand colors, private tokens, logos, customer reviews, product text, Shopify Liquid code or product-specific styling. All markup/CSS in this library is newly authored.

Sabpuja's gallery represents a storefront-specific lab; its queued items are not assumed implemented. This library remains neutral and can be adapted to WordPress, Shopify or framework projects.
