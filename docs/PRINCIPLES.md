# WebDesignToolkit visual language

- Hardline: sharp 0-2px corners, decisive borders, precise alignment.
- Tactile: offset shadow when resting, translate into shadow on press, not decorative scaling.
- Neutral-first: paper backgrounds, dark ink, a single controlled electric accent.
- Legibility: system or responsibly loaded local fonts, generous line-height, high contrast.
- Predictability: no animation if prefers-reduced-motion is enabled.
- Mobile-first: interactive targets at least approximately 44 by 44 pixels.
- Honest semantics: button for an action, link for navigation, not clickable divs.
